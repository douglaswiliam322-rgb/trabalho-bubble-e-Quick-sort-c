# Sistema de Ordenação de Dados em C (Bubble Sort e Quick Sort)

## 1. Objetivo
Desenvolver uma aplicação funcional na linguagem C para resolver situações do cotidiano, organizando informações numéricas por meio dos algoritmos de ordenação **Bubble Sort** e **Quick Sort**.

## 2. Situação-Problema
Este projeto contempla duas aplicações práticas para demonstrar a utilidade da ordenação de dados:
- **Notas de Estudantes:** Organização de um vetor com 10 notas escolares para facilitar a visualização do desempenho da turma em ordem crescente.
- **Temperaturas do Dia:** Organização de 10 registros de temperaturas inteiras coletadas ao longo do dia para identificar os momentos mais frios e mais quentes.
